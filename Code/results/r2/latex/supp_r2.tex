\section{Revision-2 Compute and Reproducibility}
\label{sup:r2compute}

The second-revision experiments comprise 137 cells, each one model, method, seed and variant.
They ran on two Jarvis Labs GPUs (A100-PCIE-40GB and A30-24GB) in about 8 GPU-hours.
Each cell writes its per-pair outputs, training logs and the trained adapter to
\texttt{Code/results/r2/} in the public repository, and every table of this revision is generated from
those files by \texttt{peat.r2.analysis} and \texttt{peat.r2.make\_tables}.
The batched trainer computes the same loss as the original per-item implementation; a unit test
(\texttt{tests/test\_r2\_equivalence.py}) confirms agreement to $10^{-5}$ on BERT-base and a Qwen2.5 decoder.
Zero-shot tasks are scored with up to 2{,}000 items each (fixed random subset) for the first seed.
